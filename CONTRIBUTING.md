# How we work (5 rules)
 
1. **One task = one issue.** Take an issue from the board, put your name on it, and move it to "In Progress".
2. **Work on your own branch**, never directly on `main`. Name it `yourname/what-you-do`, e.g. `fordorsmorehhhors/Lvizoyalization`.
3. **Open a Pull Request** when it works, write `Closes #12` in the description, and ask one teammate to look at it.
4. **Never commit** the datasets, `.env`, or passwords. Put them in `.gitignore`.
5. **Weekly 15 min call--INCHAAAAALLAH:** what's done, what's blocked, what's next.
## Commit messages
 
Just say what you did, in a few words: `add Kafka producer`, `fix log parser`.
 
## Column names
 
Use the names from `docs/data_dictionary.md` (ip, ts, method, url, status, bytes, user_agent). If you want to change one, tell the group first.
